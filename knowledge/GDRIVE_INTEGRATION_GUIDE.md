# Руководство по интеграции RAG базы знаний с Google Drive

Это пошаговое руководство объясняет, как подключить облачную папку Google Drive к ИИ-ассистенту академии, чтобы обновлять программы курсов, цены и FAQ без правок исходного кода сайта.

---

## Вариант 1: Быстрое подключение по ссылке на папку (Без настройки API)

1. Откройте ваш **Google Drive** и создайте новую папку, например: `IT_Academy_Knowledge_Base`.
2. Загрузите в нее файлы базы знаний:
   - `courses.txt` (направления обучения, стек, цены, расписание)
   - `center_info.md` (кампусы, коворкинг, контакты, менторы)
   - `faq.md` (частые вопросы, рассрочка, скидки, пробный урок)
3. Нажмите правой кнопкой мыши по папке ➔ **Поделиться (Share)** ➔ в разделе «Общий доступ» выберите: **«Все, у кого есть ссылка» (Anyone with the link)** с правами *«Читатель» (Viewer)*.
4. Скопируйте ссылку на папку. Ссылка имеет вид:
   `https://drive.google.com/drive/folders/1aBcDeFgHiJkLmNoPqRsTuVwXyZ...`
5. В интерфейсе сайта нажмите кнопку **«🔑 Gemini API & Облако»** (в шапке или в чате ассистента).
6. Вставьте скопированную ссылку (или ID папки) в поле **Google Drive Folder ID / Ссылка на папку** и нажмите **Синхронизировать с Google Drive**.
7. Ассистент импортирует из папки документы `.txt` и `.docx`.

---

## Вариант 2: Прямая загрузка через Google Cloud API Key (Live Sync)

Если вы хотите, чтобы ассистент считывал файлы прямо через официальный API Google Диска в реальном времени:

1. Перейдите в [Google Cloud Console](https://console.cloud.google.com/).
2. Создайте новый проект (или выберите существующий).
3. В разделе **APIs & Services ➔ Library** найдите и включите **Google Drive API**.
4. В разделе **APIs & Services ➔ Credentials** нажмите **Create Credentials ➔ API Key**.
5. Скопируйте созданный API Key.
6. Вставьте его в поле **Google Cloud API Key** в модальном окне настроек сайта.
7. Теперь при нажатии кнопки **Синхронизировать** система через REST API `https://www.googleapis.com/drive/v3/files` загрузит TXT-файлы и DOCX-документы из папки Google Drive в память RAG-ассистента.

---

## Архитектура работы RAG с Google Drive:
```
[ Google Drive Папка ]
         │ (Синхронизация по ID / API)
         ▼
[ gdrive_rag.js ] ➔ Загрузка TXT и извлечение текста из DOCX
         │
         ▼
[ rag.js ] ➔ Семантический поиск по ключевым запросам
         │
         ▼
[ Gemini 2.5 Flash API ] ➔ Формирование точного ответа с цитатами
```
