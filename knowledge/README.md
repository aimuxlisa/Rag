# База знаний учебного центра (Knowledge Base for RAG)

Эта папка содержит структурированные данные об учебном центре для RAG (Retrieval-Augmented Generation) ИИ-ассистента на базе Gemini API.

## Структура файлов:
1. `courses.txt` — актуальные направления, длительность, стек технологий, формат и стоимость. Этот TXT-файл используется локальным RAG-ассистентом.
2. `courses.md` — прежняя Markdown-копия каталога для справки.
3. `center_info.md` — общие сведения об академии, филиалы, менторы, партнерские IT-компании, сертификация и гарантия стажировки.
4. `faq.md` — ответы на частые вопросы абитуриентов и студентов (рассрочка, скидки, трудоустройство, ноутбуки).

## Синхронизация с Google Drive:
- В Google Cloud включите Google Drive API, настройте экран OAuth и создайте OAuth Client ID типа Web application.
- Для локального сайта добавьте `http://localhost:8080` в Authorized JavaScript origins. Если сервер запущен на другом порту, добавьте и этот порт.
- В настройках сайта укажите OAuth Client ID и ссылку или ID приватной папки, затем нажмите «Синхронизировать с Google Drive» и разрешите чтение Drive.
- Для синхронизации используются файлы `.txt`, `.docx` и Google Docs. Google Docs выгружаются как обычный текст.
- Временный OAuth-токен действует только в памяти страницы и не записывается в LocalStorage. Client ID и ID папки сохраняются в этом браузере.
- OAuth-запрос использует `drive.readonly`, то есть Google выдаёт приложению право читать файлы в Drive; временный токен хранится только в памяти страницы.
- Для публикации приложения в интернете понадобится проверка OAuth в Google Cloud. Для личного локального теста добавьте свой Google-аккаунт в список test users.
