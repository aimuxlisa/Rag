# База знаний учебного центра (Knowledge Base for RAG)

Эта папка содержит структурированные данные об учебном центре для RAG (Retrieval-Augmented Generation) ИИ-ассистента на базе Gemini API.

## Структура файлов:
1. `courses.txt` — актуальные направления, длительность, стек технологий, формат и стоимость. Этот TXT-файл используется локальным RAG-ассистентом.
2. `courses.md` — прежняя Markdown-копия каталога для справки.
3. `center_info.md` — общие сведения об академии, филиалы, менторы, партнерские IT-компании, сертификация и гарантия стажировки.
4. `faq.md` — ответы на частые вопросы абитуриентов и студентов (рассрочка, скидки, трудоустройство, ноутбуки).

## Синхронизация с Google Drive:
- Данные файлы могут быть загружены в Google Drive папку.
- В настройках чата можно добавлять документы `.txt` и `.docx`; они сохраняются в LocalStorage браузера.
- ИИ-ассистент будет индексировать документы для контекстного ответа на любые вопросы пользователей с сайта.
