# База знаний учебного центра (Knowledge Base for RAG)

Эта папка содержит структурированные данные об учебном центре для RAG (Retrieval-Augmented Generation) ИИ-ассистента на базе Gemini API.

## Структура файлов:
1. `courses.txt` — актуальные направления, длительность, стек технологий, формат и стоимость. Этот TXT-файл используется локальным RAG-ассистентом.
2. `courses.md` — прежняя Markdown-копия каталога для справки.
3. `center_info.md` — общие сведения об академии, филиалы, менторы, партнерские IT-компании, сертификация и гарантия стажировки.
4. `faq.md` — ответы на частые вопросы абитуриентов и студентов (рассрочка, скидки, трудоустройство, ноутбуки).

## Синхронизация с Google Drive:
- В Google Cloud включите Google Drive API и создайте Service Account с JSON-ключом.
- Положите JSON-ключ в локальную папку `secrets/` в корне проекта. Папка исключена из Git и закрыта от раздачи через веб-сервер.
- Поделитесь папкой Google Drive с адресом `client_email` из JSON-ключа как минимум с правом просмотра.
- В настройках сайта укажите ID или ссылку на папку и нажмите «Синхронизировать с Google Drive».
- Для синхронизации используются файлы `.txt`, `.md`, `.docx` и Google Docs. Google Docs выгружаются как обычный текст.
- Кнопка «Загрузить локальную базу» отправляет `courses.txt`, `center_info.md` и `faq.md` в эту папку. Устаревшая копия `courses.md` не загружается. Для загрузки Service Account должен иметь роль Editor.
- Приложение использует Drive API только на сервере. Ключ Service Account не отправляется в браузер; ID папки сохраняется в LocalStorage.
